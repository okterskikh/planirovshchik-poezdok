# Обмен между компьютером и iPhone

Открывайте планировщик по одному адресу: https://court-trip-planner-7c4a.okterskikh.chatgpt.site/. На iPhone используйте обычную вкладку Safari. Вход в ChatGPT не нужен. На каждом устройстве свой набор данных; автоматической синхронизации нет.

## Первый перенос

1. На компьютере откройте «Обмен данными» и нажмите «Скачать JSON».
2. Передайте файл на iPhone удобным рабочим способом, не публикуя общую ссылку на данные клиентов.
3. На iPhone откройте «Обмен данными» → «Восстановить JSON». Сначала при необходимости скачайте текущую копию телефона.
4. Выберите файл, проверьте количества и подтвердите замену. Оба устройства теперь используют одну рабочую область.

Полное восстановление заменяет набор этого браузера. Для последующего объединения независимых изменений используйте следующую процедуру.

## Последующий обмен

1. На устройстве, с которого передаёте изменения, скачайте свежий JSON.
2. Передайте файл на другое устройство. На принимающем устройстве откройте «Обмен данными» → «Объединить JSON».
3. Скачайте текущую копию кнопкой в форме, затем выберите переданный файл.
4. Просмотрите добавляемые задачи и различия. «На этом устройстве» — текущие данные принимающего устройства, «В JSON-файле» — данные переданной копии.
5. Выберите версию отдельно для каждой различающейся группы. Например, можно оставить расписание компьютера и принять результат выполнения с телефона. Справочник и порядок каждого дня выбираются отдельно.
6. Нажмите «Проверить объединение». Подтвердите выбор отметкой и нажмите «Применить объединение».
7. При необходимости скачайте полученную объединённую копию и таким же способом объедините её на первом устройстве.

Одинаковые данные не требуют выбора. Новые задачи и события истории добавляются без дублей. Отмена и Escape не применяют выбранные версии. До применения можно сменить файл — решения предыдущего файла будут сброшены.

Если программа сообщает о другой рабочей области, не пытайтесь объединять независимые наборы: сначала сохраните оба JSON. Для замены одного набора другим используйте отдельное восстановление. Старые копии не становятся новее от даты скачивания: выбирайте значения по их содержимому.

## Что проверить на реальном iPhone

Разработчик проверил логику и интерфейс обмена в Chrome/Edge, в том числе ширину 390 px. Доступа к вашему телефону у разработчика нет. Для приёмки устройства используйте вымышленные данные:

- в обычной вкладке Safari загрузите Excel/CSV через выбор файла, запланируйте задачу кнопками, запишите попытку или выполнение и скачайте CSV результатов;
- передайте тестовый JSON между компьютером и iPhone в обе стороны, выберите разные группы из двух копий и примените объединение;
- обновите страницу и полностью закройте/повторно откройте Safari: принятые данные должны сохраниться;
- оцените читаемость, размеры элементов и удобство выбора различий. Для отчёта зафиксируйте версии iOS и Safari.

Базовый запуск, восстановление JSON и сохранение заметки на вашем iPhone уже подтверждены ранее. Этот список относится к полному рабочему циклу и новой форме объединения.
