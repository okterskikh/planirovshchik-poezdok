# Проверка Excel-импорта

Дата: 15 октября 2026 года. Основание: уточнение пользователя, ТЗ 1.2, раздел 8.7.

## Результат

- 20 новых сценариев: по 10 в Chrome 155.0.8059.39 и Edge 155.0.4283.45. Все пройдены.
- 23 теста предметной логики повторно пройдены.
- 40 прежних браузерных сценариев, включая закрытие и повторный запуск, повторно пройдены.
- Ошибок JavaScript и HTTP-запросов приложения не обнаружено.

## Покрытие

Выбор через реальную кнопку файлового диалога, перетаскивание в мастер и на страницу, выбор листа и типа данных, отсутствие записи до подтверждения, отмена, повторный импорт, постоянные ID, пустые/повторные ID, даты 1900/1904, числовой формат документа `000`, логические ячейки, rich text и переносы строк, сохранённый результат формулы и его отсутствие, сжатый/несжатый ZIP, битая книга и неподдерживаемые расширения, несколько файлов и drop во время подтверждения, компоновка области загрузки 360 px.

Тестовая книга содержит вымышленные задачи и справочник. Дополнительные варианты генерируются в памяти. JSZip нужен только тестовому генератору; приложение его не использует.

## Повторение

```powershell
node --check script.js
node --test --test-isolation=none tests/step1-core.test.cjs
node tests/excel-import.cjs
node tests/step1-browser.cjs
```

Файлы результатов: `excel-import-results.json`, `step1-browser-results.json`, `step1-core-results.txt`. Снимки: `excel-drop-chrome.png`, `excel-drop-msedge.png`.

Минимальные браузеры версии 120 и реальный телефон не проверены. Технические пределы объёма отражены в ТЗ; этот отчёт не является итоговым нагрузочным испытанием шага 4. Субъективную оценку удобства и внешнего вида выполняет пользователь.

## Дополнительная проверка пустых строк

После исправления: 26 тестов логики, 22 Excel-сценария (по 11 на браузер) и 40 прежних браузерных проверок пройдены. Добавлены заготовки с FALSE, обычным приоритетом, статусом «Новая», резервным ID, данными только в несопоставленном столбце и пустыми оформленными ячейками. Они не создают задач и не блокируют ID. Реальная строка с клиентом или поручением без ID по-прежнему блокируется. Отдельно проверено создание мест с адресом и метро из задач без импорта справочника.

## Автоматические учреждения и пустое описание

После уточнения ТЗ 1.3: 28 тестов логики, 24 Excel-сценария (по 12 на браузер) и 40 регрессионных браузерных сценариев пройдены. В отдельном пустом браузерном контексте импортирована книга без справочника и с пустым описанием: три задачи, два автоматически созданных учреждения, общий ID учреждения для двух задач одного суда, пустые адрес/метро/расположение, задача с пустым описанием видна после перезагрузки. В тестах логики также проверено отсутствие столбца описания, сохранение старых привязок и нормализация названия суда.
