# Предварительная проверка на iPhone

Это проверка допуска к шагу 5, а не заявление о поддержке iPhone. Реальное устройство разработчику недоступно. Мобильная реализация объединения копий ещё не начиналась.

## Подготовленный набор

`iphone-check.zip` содержит текущие `index.html`, `style.css`, `script.js` и `iphone-check.json` с тремя вымышленными задачами. Рабочие данные пользователя в архив не включены. Все три файла приложения должны оставаться в одной распакованной папке.

## Сначала проверить запуск

1. Передать архив на iPhone удобным способом и сохранить в приложении «Файлы».
2. Нажать на ZIP, чтобы распаковать его, затем открыть созданную папку.
3. Открыть `index.html` и нажать «День», затем «Настройки».
4. Записать, в каком приложении открылся файл и переключаются ли разделы. Если видно только изображение страницы, текст HTML, пустой экран или кнопки не работают, проверка запуска не пройдена. Дальнейшие тесты в этом режиме не нужны.

Просмотр HTML через Quick Look не доказывает, что приложение запущено с JavaScript и доступом к соседним файлам. Официальная документация Apple описывает просмотр файлов и выбор доступного приложения, но не гарантирует работу данного планировщика из локальной папки.

## Если кнопки работают

На этом этапе используется только тестовое устройство без рабочих данных планировщика.

1. В «Обмене данными» выбрать «Восстановить JSON» и файл `iphone-check.json` из распакованной папки, подтвердить замену.
2. В разделе «Задачи» открыть активные задачи, добавить заметку «Проверка iPhone» и назначить дату одной задаче.
3. Полностью закрыть приложение, в котором открыт планировщик, и повторно открыть тот же `index.html` из той же папки. Проверить сохранение заметки и даты.
4. Скачать JSON через «Обмен данными», найти созданный файл в «Файлах».
5. Изменить заметку, затем восстановить скачанный JSON. Проверить возврат прежней заметки и расписания.

Для допуска к реализации шага 5 нужны успешные запуск, хранение после повторного открытия, выбор JSON и скачивание/восстановление JSON. Если что-либо не работает, зафиксировать результат и отдельно согласовать способ запуска; хостинг автоматически не добавляется.

Источники: [просмотр файлов на iPhone](https://support.apple.com/en-ca/guide/iphone/iphe4bff8827/ios), [распаковка ZIP](https://support.apple.com/en-ie/102532).
