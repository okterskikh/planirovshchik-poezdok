# Планировщик поездок

**Открыть:** https://okterskikh.github.io/planirovshchik-poezdok/

**Исходники:** https://github.com/okterskikh/planirovshchik-poezdok

Веб-планировщик задач и поездок по судам и другим учреждениям. Планирование дня и недели, приоритеты, готовность документов, заметки, результаты выполнения, импорт Excel/CSV, печать и обмен JSON-копиями между устройствами.

Приложение состоит из `index.html`, `style.css` и `script.js`. Данные сохраняются в localStorage браузера; сервер приложения и база данных не используются. Автоматической синхронизации устройств нет.

## Запуск

Откройте опубликованный сайт в обычной вкладке браузера. Для GitHub Pages источник публикации — ветка `main`, корневая папка `/`. Файл `.nojekyll` включает публикацию готовых статических файлов без Jekyll.

На компьютере можно также открыть `index.html` рядом с двумя остальными файлами. Для iPhone используйте HTTPS-сайт в Safari: предпросмотр HTML в приложении «Файлы» не обеспечивает полноценный запуск приложения.

## Перенос данных

При смене адреса сайта данные не переносятся автоматически: каждый адрес имеет своё хранилище браузера. В прежнем планировщике откройте «Обмен данными», скачайте JSON-копию, затем на новом адресе восстановите её через тот же раздел. Дальнейший обмен независимыми изменениями устройств описан в [exchange.md](exchange.md).

Рабочие JSON-копии и таблицы с клиентскими данными не нужно загружать в публичный репозиторий. В `tests/fixtures/` находятся искусственные примеры для проверок.

## Документация и проверки

- [tz.md](tz.md) — техническое задание.
- [plan.md](plan.md) — план и история разработки.
- [audit.md](audit.md) — сверка с требованиями и ограничения проверки.
- [tests/final-acceptance.md](tests/final-acceptance.md) — результаты автоматической приёмки.
- `tests/` — сценарии, тестовые данные и отчёты. Ранее созданные ZIP, снимки и отчёты отражают версии, указанные в истории разработки.

Проверки логики запускаются в Node.js:

```sh
node --test --test-isolation=none tests/step1-core.test.cjs tests/step2-core.test.cjs tests/step3-core.test.cjs tests/step4-core.test.cjs tests/step5-core.test.cjs
```

Браузерные сценарии используют Playwright и установленный Chrome/Edge; пути к окружению описаны в самих сценариях. В среде выполнения планировщика эти инструменты не нужны.

Служебная папка `site-publication/` исключена: это отдельная техническая копия для прежнего хостинга. Основные исходники, документация и материалы проверок хранятся в этом репозитории.
